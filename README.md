# Gade og Løwe

Kalkulator for geocaching-teknikkene **Gade**, **Løwe**, **Gulpertstein** og **Geotosse**, forlengs eller baklengs.

Bokstaver gjøres om til tall (A=1 … Z=26, Æ=27, Ø=28, Å=29), og sifrene brukes i beregningen.

- **Gade:** alle sifre sortert, deretter manglende sifre 0–9 lagt til. A = første siffer, B = neste osv.
- **Løwe:** partall sortert + manglende partall, deretter oddetall sortert + manglende oddetall.
- **Baklengs:** samme regler, men synkende rekkefølge (9→0).
- **Gulpertstein:** hver bokstav får sin plass i alfabetet; første tegn = A, neste = B osv. Resultater over 9 reduseres til siste siffer. Baklengs leser teksten bakfra.
- **Geotosse:** sifrene danner rad A; hvert nabopar summeres og siste siffer går til neste rad (B, C …) til én rad har ett siffer. Radens sifre er tallet.
